# Design Assets

| Folder | Contents |
|---|---|
| `brand/` | **Source of truth for logos and app icons** — hand-built SVG kit (mark, lockups, monogram, four app icons, favicon), `preview.html` and usage rules. See `brand/README.md`. |
| `brand_guides/` | Logo, colour and design guidelines (previously `DESIGN/`). |
| `html_mockups/` | Static HTML/CSS UI mockups for the patient app, ~150 files (previously the misspelled `Ptient app ui/`). Reference material for Flutter implementation, not a build target. |
| `stitch_splash/` | Stitch-exported splash screen assets. |

The mockup folders are large and generated, so they are excluded from git via `.gitignore`.
